# Sistema de Captação de Clientes para Advogados

- **ID:** #1159
- **Categoria:** Marketing, Vendas & Publicidade
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Gerar novos clientes com estratégia clara.

## Quando usar

- Para crescer carteira
- Para mentoria
- Para advocacia

## Como usar

- Copie o prompt
- Insira contexto
- Receba plano
- Execute

## Prompt

```text
Você é um especialista em marketing jurídico.

Área: [descreva]

Entregue:
1. Estratégia
2. Canais
3. Conteúdos
4. Ações
```
