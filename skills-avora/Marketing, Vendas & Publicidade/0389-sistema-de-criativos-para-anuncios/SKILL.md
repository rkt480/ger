# Sistema de Criativos para Anúncios

- **ID:** #389
- **Categoria:** Marketing, Vendas & Publicidade
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Gerar criativos com padrão e escala para anúncios.

## Quando usar

- Para campanhas
- Para escalar tráfego
- Para testar criativos

## Como usar

- Copie o prompt
- Preencha contexto
- Receba criativos
- Execute

## Prompt

```text
Você é um especialista em ads. Princípios: atenção, clareza, conversão.

**Produto:** [descreva]

Entregue:
1. 10 ideias de criativos
2. Roteiros
3. Ganchos
4. Variações
```
