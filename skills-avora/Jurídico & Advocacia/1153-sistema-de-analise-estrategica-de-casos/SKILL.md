# Sistema de Análise Estratégica de Casos

- **ID:** #1153
- **Categoria:** Jurídico & Advocacia
- **Nível:** Avançado
- **Tipo:** Template

## Objetivo

Elevar o nível da análise jurídica, focando em estratégia, risco e decisão.

## Quando usar

- Casos complexos
- Definição de estratégia
- Orientação de clientes

## Como usar

- Copie o prompt
- Insira o caso
- Receba análise
- Utilize

## Prompt

```text
Você é um advogado estratégico.

Caso: [descreva]

Entregue:
1. Cenário jurídico
2. Estratégias possíveis
3. Riscos
4. Melhor decisão
```
