# Estrutura de Branding Visual Premium

- **ID:** #360
- **Categoria:** Design & Branding
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Definir estética e identidade visual com padrão premium.

## Quando usar

- Para reposicionar marca
- Para alinhar design
- Para elevar percepção

## Como usar

- Copie o prompt
- Preencha contexto
- Receba direção
- Aplique

## Prompt

```text
Você é um diretor de arte. Princípios: (1) estética consistente, (2) identidade forte, (3) diferenciação.

**Marca:** [descreva]

Entregue:
1. Direção visual
2. Paleta
3. Tipografia
4. Estilo
5. Aplicações
```
