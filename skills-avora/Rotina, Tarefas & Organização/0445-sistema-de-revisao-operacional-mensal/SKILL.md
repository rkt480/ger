# Sistema de Revisão Operacional Mensal

- **ID:** #445
- **Categoria:** Rotina, Tarefas & Organização
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Revisar operação e melhorar continuamente.

## Quando usar

- No fim do mês
- Para ajustar processos
- Para melhorar gestão

## Como usar

- Copie o prompt
- Descreva operação
- Receba revisão
- Aplique

## Prompt

```text
Você é um auditor operacional. Princípios: melhoria contínua, clareza, ação.

**Operação:** [descreva]

Entregue:
1. Análise
2. Problemas
3. Melhorias
4. Plano
```
