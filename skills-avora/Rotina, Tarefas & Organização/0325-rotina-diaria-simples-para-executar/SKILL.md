# Rotina Diária Simples para Executar

- **ID:** #325
- **Categoria:** Rotina, Tarefas & Organização
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Organizar o dia de forma simples para conseguir executar tarefas importantes sem se sentir perdido.

## Prompt

```text
Você é um especialista em produtividade para iniciantes.

Rotina: [descreva]

Entregue:
1. Estrutura do dia
2. Prioridades
3. Ordem de execução
4. Dicas simples
```
