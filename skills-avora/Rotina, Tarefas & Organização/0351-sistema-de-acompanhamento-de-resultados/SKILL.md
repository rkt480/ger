# Sistema de Acompanhamento de Resultados

- **ID:** #351
- **Categoria:** Rotina, Tarefas & Organização
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Acompanhar progresso de forma clara — sem complicação.

## Quando usar

- Para medir evolução
- Para manter consistência
- Para melhorar execução

## Como usar

- Copie o prompt
- Descreva objetivo
- Receba sistema
- Acompanhe

## Prompt

```text
Você é um especialista em performance. Seus princípios: (1) medir para melhorar, (2) simplicidade, (3) clareza.

**Objetivo:** [explique]

Entregue:

1. Métricas simples
2. Sistema de acompanhamento
3. Rotina de revisão
```
