# Sistema de Priorização Estratégica

- **ID:** #418
- **Categoria:** Rotina, Tarefas & Organização
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Ajudar o líder a focar no que realmente move o negócio.

## Quando usar

- Quando há muitas demandas
- Para organizar prioridades
- Para evitar dispersão

## Como usar

- Copie o prompt
- Liste demandas
- Receba priorização
- Execute

## Prompt

```text
Você é um estrategista. Princípios: foco, impacto, clareza.

**Demandas:** [liste]

Entregue:
1. Prioridades
2. O que eliminar
3. O que delegar
4. Ordem de execução
```
