# Sistema de Indicadores Operacionais Simples

- **ID:** #391
- **Categoria:** Rotina, Tarefas & Organização
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Medir o que realmente importa sem complicação.

## Quando usar

- Para acompanhar resultados
- Para melhorar operação
- Para tomar decisões

## Como usar

- Copie o prompt
- Descreva operação
- Receba indicadores
- Acompanhe

## Prompt

```text
Você é um analista operacional. Princípios: (1) medir o essencial, (2) clareza, (3) ação.

**Operação:** [descreva]

Entregue:
1. Indicadores principais
2. Como medir
3. Frequência
4. Interpretação
```
