# Sistema de Propostas para Agência

- **ID:** #1101
- **Categoria:** Operações, RH & Gestão
- **Nível:** Avançado
- **Tipo:** Geração

## Objetivo

Criar propostas claras, profissionais e que aumentam fechamento.

## Prompt

```text
Você é um especialista em vendas.

Serviço: [descreva]

Entregue:
1. Estrutura da proposta
2. Texto completo
3. Argumentos
4. CTA
```
