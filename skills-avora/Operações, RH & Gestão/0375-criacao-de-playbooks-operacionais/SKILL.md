# Criação de Playbooks Operacionais

- **ID:** #375
- **Categoria:** Operações, RH & Gestão
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Criar guias passo a passo para tarefas recorrentes da equipe.

## Quando usar

- Para treinar equipe
- Para padronizar execução
- Para reduzir dependência do líder

## Como usar

- Copie o prompt
- Descreva tarefa
- Receba playbook
- Aplique

## Prompt

```text
Você é um especialista em playbooks. Princípios: (1) clareza, (2) passo a passo, (3) execução simples.

**Tarefa:** [descreva]

Entregue:
1. Passo a passo
2. Checkpoints
3. Erros comuns
4. Dicas práticas
```
