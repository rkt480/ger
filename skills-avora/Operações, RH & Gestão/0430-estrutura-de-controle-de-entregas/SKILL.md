# Estrutura de Controle de Entregas

- **ID:** #430
- **Categoria:** Operações, RH & Gestão
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Garantir que entregas sejam feitas com qualidade e prazo.

## Quando usar

- Para controlar prazos
- Para organizar entregas
- Para evitar atrasos

## Como usar

- Copie o prompt
- Liste entregas
- Receba controle
- Aplique

## Prompt

```text
Você é um gestor operacional. Princípios: controle, clareza, consistência.

**Entregas:** [liste]

Entregue:
1. Sistema de controle
2. Acompanhamento
3. Alertas
4. Ajustes
```
