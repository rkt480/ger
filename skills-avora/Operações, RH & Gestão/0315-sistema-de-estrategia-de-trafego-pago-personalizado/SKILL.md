# Sistema de Estratégia de Tráfego Pago Personalizado

- **ID:** #315
- **Categoria:** Operações, RH & Gestão
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Criar campanhas de tráfego pago com foco em geração de leads e clientes.

## Quando usar

- Para atrair clientes
- Para escalar negócio
- Para campanhas

## Como usar

- Copie o prompt
- Preencha contexto
- Receba estratégia
- Execute

## Prompt

```text
Você é um especialista em tráfego pago. Princípios: (1) segmentação, (2) clareza, (3) conversão.

**Serviço:** [descreva]
**Público:** [explique]

Entregue:

1. Estratégia de campanha
2. Público-alvo
3. Criativos
4. Copy
5. Métricas
```
