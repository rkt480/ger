# Sistema de Organização de Rotina Jurídica

- **ID:** #1157
- **Categoria:** Operações, RH & Gestão
- **Nível:** Iniciante
- **Tipo:** Template

## Objetivo

Organizar o dia para produzir mais e reduzir sobrecarga.

## Quando usar

- Quando está sobrecarregado
- Para organizar tarefas
- Para ganhar tempo

## Como usar

- Copie o prompt
- Descreva rotina
- Receba organização
- Aplique

## Prompt

```text
Você é um especialista em produtividade.

Rotina: [descreva]

Entregue:
1. Organização
2. Prioridades
3. Ajustes
```
