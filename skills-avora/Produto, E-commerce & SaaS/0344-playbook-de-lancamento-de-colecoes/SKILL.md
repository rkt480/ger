# Playbook de Lançamento de Coleções

- **ID:** #344
- **Categoria:** Produto, E-commerce & SaaS
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Criar lançamentos estruturados que geram expectativa e vendas.

## Quando usar

- Ao lançar produtos
- Para campanhas sazonais
- Para escalar faturamento

## Como usar

- Copie o prompt
- Preencha contexto
- Receba plano
- Execute

## Prompt

```text
Você é um estrategista de lançamentos. Princípios: (1) antecipação, (2) narrativa, (3) timing.

**Coleção:** [descreva]
**Objetivo:** [explique]

Entregue:
1. Estratégia de lançamento
2. Linha do tempo
3. Conteúdos
4. Campanhas
5. Pós-lançamento
```
