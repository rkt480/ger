# Sistema de Criação Rápida para Conteúdo

- **ID:** #205
- **Categoria:** Direção Criativa
- **Nível:** Iniciante
- **Tipo:** Geração

## Objetivo

Criar conteúdo com velocidade e consistência usando estrutura clara.

## Quando usar

- Rotina de conteúdo
- Falta de tempo
- Produção contínua
- Redes sociais

## Como usar

- Copie o prompt
- Preencha contexto
- Receba conteúdos
- Publique

## Prompt

```text
Você é um criador de conteúdo. Seus princípios: (1) consistência, (2) clareza, (3) simplicidade, (4) velocidade.

**Tema:** [descreva]
**Objetivo:** [explique]

Entregue:

1. 5 conteúdos prontos
2. Estrutura
3. Ganchos
4. CTA
```
