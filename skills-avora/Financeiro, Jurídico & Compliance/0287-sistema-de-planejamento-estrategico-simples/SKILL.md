# Sistema de Planejamento Estratégico Simples

- **ID:** #287
- **Categoria:** Financeiro, Jurídico & Compliance
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Transformar ideias soltas em um plano claro de ação — focado em crescimento de faturamento.

## Quando usar

- Quando não sabe por onde começar
- Para organizar o negócio
- Para crescer com direção

## Como usar

- Copie o prompt
- Preencha com seu negócio
- Receba plano estruturado
- Execute

## Prompt

```text
Você é um estrategista de negócios. Princípios: simplicidade, clareza, execução.

Negócio: [descreva]
Objetivo: [explique]
Dificuldades: [liste]

Entregue:
1. Diagnóstico
2. Prioridades
3. Plano de ação
4. Próximos passos
```
