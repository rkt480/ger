# Sistema de Análise Financeira Simplificada

- **ID:** #293
- **Categoria:** Financeiro, Jurídico & Compliance
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Entender claramente entradas, saídas e lucro do negócio.

## Quando usar

- Para organizar finanças
- Para saber se está lucrando
- Para tomar decisões melhores

## Prompt

```text
Você é um consultor financeiro.

Receitas: [descreva]
Despesas: [liste]

Entregue:
1. Análise financeira
2. Lucro real
3. Problemas
4. Melhorias
```
