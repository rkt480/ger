# Sistema de Escala com Equipe Pequena

- **ID:** #408
- **Categoria:** Liderança & Equipes
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Crescer sem perder controle e qualidade.

## Quando usar

- Para escalar operação
- Para crescer faturamento
- Para organizar time

## Como usar

- Copie o prompt
- Descreva operação
- Receba plano
- Execute

## Prompt

```text
Você é um estrategista de escala. Princípios: processos, clareza, foco.

**Negócio:** [descreva]

Entregue:
1. Plano de escala
2. Gargalos
3. Ajustes necessários
4. Prioridades
```
