# Sistema de Conteúdo Jurídico com Copy

- **ID:** #1160
- **Categoria:** Conteúdo & Copy
- **Nível:** Intermediário
- **Tipo:** Template

## Objetivo

Criar conteúdo que gera autoridade e atrai clientes.

## Quando usar

- Para Instagram / LinkedIn
- Para atrair clientes
- Para posicionamento

## Como usar

- Copie o prompt
- Insira o tema
- Receba conteúdo
- Publique

## Prompt

```text
Você é um copywriter jurídico.

Tema: [descreva]

Entregue:
1. Ideias de conteúdo
2. Post completo
3. Ganchos
4. CTA
```
