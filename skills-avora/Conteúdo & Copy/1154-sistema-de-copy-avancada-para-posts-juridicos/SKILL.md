# Sistema de Copy Avançada para Posts Jurídicos

- **ID:** #1154
- **Categoria:** Conteúdo & Copy
- **Nível:** Avançado
- **Tipo:** Template

## Objetivo

Criar conteúdos com maior impacto, retenção e conversão.

## Quando usar

- Posts no Instagram/LinkedIn
- Anúncios
- Conteúdo educativo

## Como usar

- Copie o prompt
- Defina o tema
- Receba a copy
- Publique

## Prompt

```text
Você é um copywriter jurídico especialista.

Tema: [descreva]

Entregue:
1. 5 ganchos fortes
2. Post completo
3. Estrutura persuasiva
4. CTA
```
